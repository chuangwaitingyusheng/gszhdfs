# 格式转换大法师

一款 Windows 桌面端的办公文档处理工具。

## 下载

请到 [Releases](https://github.com/chuangwaitingyusheng/gszhdfs/releases) 页面下载最新版本：

- **格式转换大法师_x.x.x_x64-setup.exe** — Windows 64 位安装包

> 本仓库仅用于分发安装包，不包含源代码。

## 功能

- **PDF 工具** — 合并、拆分、压缩、旋转、页面重排、加密/解密
- **PDF 与图片** — 图片转 PDF、PDF 转图片
- **Office 转换** — Word / Excel / PPT 与 PDF 互转
- **OCR 文字识别** — 从图片和扫描件提取文字，支持 `.7z` 压缩包批量处理
- **音频 / 视频** — 常用格式转换

## 安装说明

1. 下载 `格式转换大法师_x.x.x_x64-setup.exe`
2. 双击运行，按提示完成安装
3. 首次运行如遇 Windows SmartScreen 提示，选择「更多信息」→「仍要运行」

**系统要求**：Windows 10 及以上，64 位
