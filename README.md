# gszhdfs

用于发布「格式转换大法师」的版本。

官方网站：**<https://gszhdfs.cn>**

本仓库**只发布安装包，不包含源代码**。请到 [Releases](https://github.com/chuangwaitingyusheng/gszhdfs/releases) 页面下载。

> 格式转换大法师是一款 Windows 桌面端办公工具箱，覆盖 PDF、图片、Excel、条码二维码、音视频、文件整理等场景，共 **7 大类 60 个工具**。所有文件都在**你自己的电脑上处理，不上传服务器**。

## 下载

请到 [Releases](https://github.com/chuangwaitingyusheng/gszhdfs/releases) 页面下载最新版本：

- **geshizhuanhuan_dafashi_x.x.x_x64-setup.exe** — Windows 64 位安装包

## 安装说明

1. 下载 `geshizhuanhuan_dafashi_x.x.x_x64-setup.exe`
2. 双击运行，按提示完成安装
3. 首次运行如遇 Windows SmartScreen 提示，选择「更多信息」→「仍要运行」

**系统要求**：Windows 10 及以上，64 位

## 使用说明

- 首次使用需**微信扫码登录**。
- 各工具按次计费，界面会显示剩余次数；开通会员后不限次使用。
- 使用工具时需**保持联网**，以便校验剩余次数与积分。

## 更新日志

### 0.1.1

**新增功能**

- **PDF 骑缝章**：把印章按页切分后分别盖在多页边缘，合起来是一枚完整的章，可有效防止抽换页。
- **GIF 去背景**：逐帧去除动图背景，输出带透明通道的 GIF。

**AI 抠图**

- 修复显卡显存不足时被误判为「融合失败」反复重试的问题；显存不足会自动降级重试一次，仍失败则改用 CPU。
- 记住在显卡上不可用的模型，避免每次重复尝试（大幅缩短等待时间）。
- 修复长时间使用后内存占用持续升高的问题，现在模型缓存会自动回收。
- 推理时默认使用低功耗模式，降低对日常使用的影响。
- 修复模型名称纵向换行导致排版错乱。
- 证件照换底色新增模型选择与参数微调（阈值、边缘、羽化）。

**PDF 插图**

- 打开 PDF 默认适应窗口，整页完整可见，并随窗口大小自动调整。
- 修复缩放后页面周围出现大片空白和多余滚动条。
- 拖动图片改为逐帧合批处理，明显更流畅。
- 修复拖动时图片跳到别处、松手后位置不准的问题。
- 拖动时鼠标移出预览区不再中断。

**Excel 转 PDF**

- 支持 CSV / TSV 文件，自动识别 UTF-8、GBK 等编码，修复中文乱码。
- 修复转换全部失败时仍显示「成功」且不提示原因的问题。

**其他**

- 大文件 PDF 改为按需渲染，并显示加载进度，不再像卡死。
- 优化模型下载，支持分段并行与代理环境。
- 新增运行日志查看，便于排查问题。
